# Packaging Design Workflow

面向不锈钢餐具和彩盒项目的 AI 协作流程技能：来稿与需求 → 多方向比较 → 选择与精修 → 多角度和灯光 → 印刷版面检查与交付。

这是流程技能，不是在线设计网站，也不是一键生成可直接生产文件的程序。图像生成、三维建模、排版软件及工厂审核需由使用环境提供。

## 使用
将本仓库内容放入支持 SKILL.md 的工具所读取的技能目录，目录名保持 packaging-design-workflow。请遵循所用工具的安装方式。

示例请求：“使用 packaging-design-workflow，依据我提供的餐具照片与已确认刀模，先整理需求并做两个可比方向；选定后再精修，最终给出印前待确认清单。”

- 入口： [SKILL.md](SKILL.md)
- 阶段和版本记录： [references/project-record.md](references/project-record.md)
- 印刷交付检查： [references/print-gates.md](references/print-gates.md)

只做局部改稿时从当前阶段开始，不重复已经确认的工作。没有图像或编辑工具时，技能会区分能够提供的方案和无法生成的成品。

## 可选配合
