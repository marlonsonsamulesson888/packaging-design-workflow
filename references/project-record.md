# 项目记录模板

按当前阶段选用字段，不为简单改稿强制建立大量文档。可以复制此模板到用户指定的项目目录。

## 需求与素材
- 本次任务与不修改范围：
- 产品类型、件数与 SKU；各类数量、内托或上下层分配、合计：
- 已确认尺寸、单位、结构及依据：
- 素材清单：文件名 / 来源 / 版本 / 用途 / 使用许可 / 是否允许公开
- 文案、Logo、条码数据的确认人：
- 目标渠道、交付格式与验收标准：
- 可用工具；缺失能力：
- 待确认事项，以及影响哪个阶段：

## 阶段与选择
- 当前阶段：
- 比较方向与差异：
- 用户选定或授权自行选择的依据：
- 平面母版文件和版本：
- 面位记录：面名 / 内容 / 上方向 / 相邻面
- 精修范围：
- 多角度记录：视图文件 / 母版版本 / 可见面 / 灯光 / 是否仅为概念

## 验收与交付
- 检查项 / 实际证据 / 结果 / 检查人或工具 / 日期：
- 未通过项及阻断范围：
- 实际交付文件与版本：
- 客户待确认项：
- 印厂或结构工程师待确认项：

## 错误复盘
- 现象和涉及版本：
- 已确认原因；尚未证实的猜测：
- 修复及复查证据：
- 预防检查和适用情形：
- 是否含客户资料；公开前如何脱敏：
